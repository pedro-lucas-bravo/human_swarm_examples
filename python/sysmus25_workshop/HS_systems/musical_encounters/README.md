# Musical Encounters

Refer to the image below. The spherical agents are autonomous, enabling them to move automatically inside the spherical boundary that surrounds them. The cubic agents are user-controlled and can be moved only by a user and placed at any location, inside or outside the spherical boundary. All agents have a semi-transparent spherical radius that allows the detection of neighbouring agents when they cross this radius. The autonomous agents move at a constant speed in a straight line and change direction at random when they bounce against the spherical boundary. When one agent detects another, we call this an ``encounter'' and a musical note is played back. The musical note is assigned from a predefined musical scale; depending on how far an agent is from the centre of the spherical boundary, the note will be different. Additionally, depending on the agent's speed, there will be a certain amount of reverb in the sound. In this way, if we have a few agents with a slow speed, we will have fewer encounters than having more agents with a higher speed. In terms of user interaction, apart from moving the user-controlled agents, it is possible to change parameters such as the number of agents and their speed. Considering all these elements together, this can be seen as a music performative tool supported by a multi-agent system.
